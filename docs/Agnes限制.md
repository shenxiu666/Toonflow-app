## 一、视频模型：Agnes Video 2.5 Flash

### 1.1 价格

| 项目 | 价格 |
| :--- | :--- |
| 刊例价 | **$0.025 / 秒** |
| 体验价 | **$0 / 秒**（限时免费） |

免费期间，输出视频秒数、输入视频秒数、参考图片均按 **$0** 计费。

### 1.2 免费限制

| 限制项 | 规则 |
| :--- | :--- |
| 输出分辨率 | **仅支持 720P** |
| 单段视频时长 | **4–12 秒** |
| 参考图片 | 最多 **5 张** |
| 参考音频 | 最多 **3 段** |
| 参考视频 | **不支持** |
| 超限处理 | 校验在任务创建前执行，返回 HTTP 400，**不创建任务、不产生费用** |
| 免费性质 | **限时免费**，非永久免费承诺；价格可能随时调整 |

### 1.3 速率限制（RPM）

| 用户类型 | 视频模型 RPM |
| :--- | :--- |
| 免费 / 默认用户 | **1 RPM** |
| 企业认证用户 | **2 RPM** |
| Token Plan 订阅用户 | **5 RPM** |

> 免费用户的主要瓶颈是 **1 RPM**，即每分钟仅能发起 1 次视频生成请求。  
> 超过 RPM 限制时，API 返回 **429 Too Many Requests**，建议实现带退避策略的重试机制。

### 1.4 每日视频秒数配额

| 用户类型 | 每日视频秒数配额 |
| :--- | :--- |
| Token Plan 订阅用户（Starter / Plus / Pro） | **500 秒 / 天** |
| 免费用户 | 官方未明确列出；主要约束为 **1 RPM**。第三方评测提及每日赠送积分可间接换算约 100 秒，仅供参考，非官方直接规定 |

RPM 与每日秒数配额**同时生效**，共同决定实际可用量。

### 1.5 参考图片计费规则

| 项目 | 规则 |
| :--- | :--- |
| 标准计费（Agnes Video 2.5） | 前 **5 张**输入图片免费；从第 **6 张**起，每张 **$0.005** |
| Flash 限时免费期间 | 参考图片按 **$0** 计费 |
| 数量上限 | `reference` 模式下 `images` 最多 **5 张**；超出返回 HTTP 400，错误信息 `images length must not exceed 5` |

## 二、图片模型限制

### 2.1 速率限制（RPM，按输出分辨率划分）

图片模型的 RPM 按输出分辨率档位划分。**Public RPM** 为允许发起请求的频率，**Effective RPM** 为实际执行上限。

| 用户类型 | 分辨率档位 | Public RPM | Effective RPM |
| :--- | :--- | ---: | ---: |
| **免费 / 默认用户** | 1K | 30 | **20** |
| | 2K | 20 | **10** |
| | 3K | 2 | **1** |
| | 4K | 1 | **1** |
| **企业认证用户** | 1K | 60 | **40** |
| | 2K | 40 | **20** |
| | 3K | 2 | **1** |
| | 4K | 2 | **1** |
| **Token Plan 用户** | 1K | 120 | **100** |
| | 2K | 120 | **80** |
| | 3K | 2 | **1** |
| | 4K | 2 | **1** |

### 2.2 关键说明

- **3K / 4K 是限制分水岭**：无论哪种用户类型，请求 3K 或更高分辨率时，实际 RPM 均骤降至 **1**，即每分钟最多成功生成 1 张高分辨率图片。
- **RPM 与订阅配额同时生效**：Token Plan 用户除 RPM 外，还受订阅配额约束（例如每天最多生成 4,000 张图片的档位限制），两种限制共同作用。
- **数值可能调整**：官方注明 RPM 限制属于运营参考值，可能根据基础设施容量和服务稳定性调整。

### 2.3 输入参考图片计费（与视频标准计费共用规则）

| 项目 | 规则 |
| :--- | :--- |
| 前 5 张输入图片 | **免费** |
| 第 6 张起 | 每张 **$0.005** |
| Flash 限时免费期间 | 按 **$0** 计费 |

## 三、通用注意事项

1. **超限校验不扣费**：视频模型的图片/音频数量、分辨率、时长等校验在任务创建和计费之前执行，超限请求不会产生费用。
2. **429 处理**：触发 RPM 限制时返回 `429 Too Many Requests`，建议使用退避重试。
3. **免费性质**：视频 Flash 的 $0/秒为**限时免费**促销，不构成永久免费承诺。
4. **数据来源优先级**：以官方域名 `agnes-ai.com` / `wiki.agnes-ai.com` 的文档为准；第三方社区整理仅作参考。
